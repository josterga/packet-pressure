PACKET PRESSURE

Extend the route. Hold the endpoint.

HOW TO PLAY

Draw one card, play one card each turn. Cards chain when output channel matches the next card's input. Routes need 2+ nodes to score. The player who places the exit node scores its PKT value.

Score to win: 1200 · Max rounds: 4 · 3 players

Card types

  • ⇒ Relay — extends a route
  • ⊣ Terminal — closes any open route (≥2 nodes)
  • ⊕ Amplifier — like relay; exit node value ×2
  • ⚠ Noise — destroys scoring routes on target channel
  • ⊘ Filter — like relay; immune to noise on its input channel

LOG
HOW TO PLAY
GOAL

First to 1200 points wins. If no one does, most points after round 4 wins.

YOUR TURN

Draw one card, then click a card in your hand to play it.

ROUTES

Cards chain when each node's output channel matches the next node's input. Routes need 2+ nodes to score. Max 3 hops; max 3 routes open at once. No output channel can appear twice in one route. Any player can extend any open route — whoever holds the exit node when a route closes scores it.

CARD TYPES
⇒ Relay — extends a route (input→output); starts a new route if cap allows
⊣ Terminal — closes any open route (≥2 nodes); terminal's own PKT value scores
⊕ Amplifier — like relay; if exit node at scoring, value ×2
⚠ Noise — destroys all scoring routes whose current output channel matches; only legal when such a route exists
⊘ Filter — like relay; route is immune to noise on this card's input channel
SCORING

At round end, all valid routes (≥2 nodes) score. Only the exit node's PKT value counts. The exit node's owner collects the points.

HINTS

Green labels under each card show where it can be played. Cards with no valid label cannot be played this turn.
